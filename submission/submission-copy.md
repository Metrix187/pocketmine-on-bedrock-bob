# Project description (under 100 words)

PocketMine-on-Bedrock modernizes an existing PocketMine-MP server with IBM Bob as the development loop. Bob analyzed dependencies, committed PHP and protocol refactors, wrote test sources, and supported live debugging. Human-provided 26.52 fixes and Bob verification addressed jigsaw packet ordering and hashed block IDs. The demo shows a fresh Windows deployment reaching Done, UDP 19132 listening, and a real Bedrock 26.52 client joining the world. The repository includes session excerpts, source, and a runnable package. Theme 2: Modernize What Matters. Public hosting remains future work.

## Track
Theme 2: Experienced Developers - Modernize What Matters

## Stack
IBM Bob IDE, PocketMine-MP, PHP 8.4 CLI (8.2 minimum), Composer, Amber-PM BedrockProtocol/BedrockData, RakLib UDP, Windows, Git/GitHub, Minecraft Bedrock 26.52. FFmpeg assembled the demo.
